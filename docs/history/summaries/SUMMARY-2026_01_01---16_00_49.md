## Technical Details

### SensitiveLevel Enum Conversion

The DataMapper constructor requires `SensitiveLevel` enum values, but Symfony configuration only supports strings. The `DataMapperFactory` bridges this gap:

```php
// Convert sensitive keys string values to SensitiveLevel enums
$sensitiveKeysEnum = [];
foreach ($sensitiveKeys as $key => $level) {
    $sensitiveKeysEnum[$key] = SensitiveLevel::from($level);
}
```

### Forward Compatibility

The cascade collection feature is prepared for when the core library implements it:

```php
// Enable cascade collection if configured and method exists
if ($this->enableCascadeCollection && method_exists($dataMapper, 'enableCascadeCollection')) {
    $dataMapper->enableCascadeCollection();
}
```

    enable_lineage_collection: true
    enable_cascade_collection: false
    enable_profiler: true
    
    custom_hydrators:

        token: hide
    
    default_sensitive_level: show

        enabled: true
        service: 'logger'
        channel: 'data_mapper'
